# SB-013-2: leftovers and an edge case of the trailing persistence

- `PositionGuardStore.findAll` and `GuardRow` are no longer used (`GuardLoader` reads `findAllGuards`); removing a
  public method was left for a separate task.
- `TrailingStateWriter` compares with the last saved state in memory. If a symbol is sold by a verdict (disarmed in
  `ExecutionService`, no tick in between), bought again, and the very first tick after the new fill activates at
  exactly the old best price, that write is skipped and a restart would see the guard as not activated. Clearing
  the writer's memory at a fill would need a new `ExecutionService` dependency.
