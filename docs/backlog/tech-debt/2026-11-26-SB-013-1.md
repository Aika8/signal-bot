# SB-013-1: D-004 trailing factors live in the adapter

`ExecutionService.trailingFor` holds the D-004 starting values (activation 2R, offset 1 × ATR, spread 0.1 × ATR) as
private constants, because the task's paths do not include `application`. Their natural home is a pure factory
next to `TrailingLevels`/`StopPolicy` in `application`, so the backtest (D-005) can reuse the same rule.
