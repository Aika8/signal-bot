# The screener's bars request has no `start`, so Alpaca may return only today's bar
- where: `adapters/src/main/java/io/github/signalbot/screen/ScreenRunner.java` (`dailyBars`: `timeframe=1Day&limit=60`, no `start`)
- why it matters: SB-002 found that without `start` Alpaca returns only the current day; with Wilder's ATR(14) every symbol would then print `ERROR no ATR (1 bars)` instead of a row. The request also keeps today's possibly still-open bar, which `AlpacaPriceHistory` drops. Reusing `PriceHistory.dailyBars` (or its query) would fix both; not done because SB-004 only changes the ATR rule.
- found by: SB-004, executor, 2026-11-26
